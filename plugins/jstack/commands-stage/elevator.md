Invoke the `jstack:elevator` skill. Everything after the command is its focus: $ARGUMENTS

Call it first, always. Whether the skill is there is not something this session can judge from
the outside — only the Skill tool's own result answers it, so a turn that reports the skill
missing without a failed call in it has fabricated the reason it went by hand.

**Only once that call has actually failed** — the tool returned an error, or the text it loaded
is older than this file — say so in one line naming the error, then deliver by hand: settle and
commit anything outstanding first, then where it stands, what it took, what is next — a block
each, blank line between, four to six sentences all in. No paths, symbol names, shas, issue
numbers, counts or headers.
