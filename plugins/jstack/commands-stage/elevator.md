Invoke the `jstack:elevator` skill. Everything after the command is its focus: $ARGUMENTS

**If that skill is not available** — plugin not installed, or a cached version older than the
skill — say so in one line, then deliver by hand: settle and commit anything outstanding first,
then where it stands, what it took, what is next — a block each, blank line between, four to
six sentences all in. No paths, symbol names, shas, issue numbers, counts or headers.
