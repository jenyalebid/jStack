# /jstack:elevator

Report's obligations, a person's mouth. Said out loud, broken where the thought turns, carrying nothing the user would have to open.

## 1. Settle before speaking

Shorter delivery, same debt. Work in this session that is not yet settled and committed → run `/jstack:report` steps 1 and 2 first: fix or file every finding, then push. Report already ran this session → go straight to speaking. Nothing was produced — a question, a look around → nothing to settle; answer and stop.

The shas and issue numbers exist so the work is real. None of them are said out loud.

## 2. Three beats, a block each

A blank line between blocks, one to three sentences inside one. Never the whole thing as a single wall — an unbroken block is the failure this skill exists to end, however short it is.

- **Where it stands** — open on the state, in the shape of the ask as it was first put. A question gets its answer, a job gets whether it works.
- **What it took** — what was actually wrong, and what changed it. Cause and effect, never an inventory of edits.
- **What is next** — the next move, what is waiting on the user, or that it is closed.

Anything unfinished, blocked or unverified takes its own block rather than being folded into a clause. Compression buys no silence — the line that would have gone under *Not Done* is the one that must survive it.

## 3. How it sounds

Four to six sentences all in, around a hundred words, three or four blocks. No headers, no bullets, no bold, no backticks.

Out: paths, file and symbol names, shas, issue numbers, test counts, tool and skill names, and every number that decorates rather than decides. In: the plain name of the thing — the retry loop, the login redirect, the nightly sweep. Something with no plain name gets described by what it does, in three words.

Say it the way it would be said standing next to the user. No preamble, no closing offer, no hedge.

## 4. Focus

Everything after the command points the paragraph: `/elevator the sweep — is it actually running`. A focus narrows: answer that aspect and drop the rest, including the parts worth being proud of. No focus → this session's unit of work. A focus on something the session never touched → say so in one line rather than composing an answer out of inference.

## 5. Read it back

Could the user repeat it to someone else without opening anything? Does the first sentence answer what was actually asked? Does every block turn on a new thought, or is one of them a wall? Does the long version owe anything this one dropped?
